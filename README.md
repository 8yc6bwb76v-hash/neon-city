# NEON CITY

iPhoneで使うことを想定した、個人用の生活時間プランナー試作品です。

## できること（試作版）
- タスクカードの追加・編集・削除
- ドラッグ＆ドロップでカードの順番変更（PC/対応ブラウザ）
- タスクの完了チェック・未完了タスク時間を差し引いた自由時間の概算表示\n- タスクの種類別ネオンカラー
- 所要時間からの簡易タイムライン生成
- 開始時刻指定カード
- 就寝時刻・一日の開始時刻設定
- 就寝までの残り時間表示
- 長期目標と小さな一歩の保存
- localStorageによる端末内保存

## 使い方
`index.html` をブラウザで開くか、GitHub PagesなどのHTTPS対応ホスティングに配置してください。
iPhoneではSafariで公開URLを開き、「共有」→「ホーム画面に追加」でPWA風に利用できます。

## 注意
これは最初のUI/操作確認用プロトタイプです。AI連携、クラウド同期、通知、実績時間の記録、スマホでのカード並べ替え操作は今後の実装項目です。
ブラウザのデータ消去や端末変更でlocalStorageのデータは失われる場合があります。重要なデータのバックアップ機能はまだありません。
